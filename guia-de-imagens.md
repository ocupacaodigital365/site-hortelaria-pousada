### Instruções para Substituição de Imagens

1. **Substituição dos Arquivos**: Para substituir as imagens de demonstração pelas imagens definitivas da pousada, basta copiar os novos arquivos com os mesmos nomes para a pasta `dist/assets/img/`.
2. **Otimização**: Recomenda-se utilizar compressores de imagem como TinyPNG ou converter para `.webp` para obter o máximo desempenho de carregamento na Hostinger.
